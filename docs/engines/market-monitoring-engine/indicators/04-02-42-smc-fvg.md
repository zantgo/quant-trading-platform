# SMC Fair Value Gap (FVG / Imbalances)

**Version:** 11.0 (2026-08-26) — see docs/CHANGELOG.md for the canonical version history.

**Group:** Institutional

## 1. Introduction — Trading Function

A Fair Value Gap (FVG) is a 3-candle pattern where the first and third candles do not overlap in price, creating an "imbalance" — a price zone where the auction moved too fast to establish fair value. These imbalances tend to act as magnets, attracting price back to fill the gap. A **bullish FVG** forms when candle 3's low is above candle 1's high (price gapped up with no retracement). A **bearish FVG** forms when candle 3's high is below candle 1's low (price gapped down with no retracement). The FVG remains "open" until price trades back into the zone ("partially filled") and closes beyond it ("mitigated"). Mitigated FVGs can later invert and act as support/resistance.

## 2. Detection Algorithm

```
For each completed candle triplet (n-2, n-1, n):
  Bullish FVG: Low[n] > High[n-2] → gap zone = [High[n-2], Low[n]]
  Bearish FVG: High[n] < Low[n-2] → gap zone = [Low[n-2], High[n]]

FVG lifecycle:
  Created → tracked as "open"
  Price enters zone → "partially filled"
  Price closes beyond zone → "mitigated" (removed)
```

## 3. Normalization

| Condition | Normalized | Label |
|-----------|-----------|-------|
| Bullish FVG open (price below gap, magnet above) | +0.45 | `SMC_FVG_BULLISH_OPEN` |
| Bearish FVG open (price above gap, magnet below) | −0.45 | `SMC_FVG_BEARISH_OPEN` |
| No active FVG | 0.0 | `SMC_FVG_NONE` |

The `values` sub-map carries: `fvg_top`, `fvg_bottom`, `fvg_bullish` (0/1).

## 4. Signals

| SignalKind | Label Pattern | Trigger | Direction |
|-----------|--------------|---------|-----------|
| LevelTest | SMC_FVG_BULLISH_OPEN | Bullish FVG active (gap above price) | Bullish |
| LevelTest | SMC_FVG_BEARISH_OPEN | Bearish FVG active (gap below price) | Bearish |

## 5. Scoring

`smc_fvg` is `directional: true`. Open FVGs provide price targets and potential fill zones. Mitigated FVGs can invert as structural levels.
