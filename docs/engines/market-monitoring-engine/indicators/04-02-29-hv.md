# Historical Volatility (20)

**Version:** 11.0 (2026-08-26) — see docs/CHANGELOG.md for the canonical version history.


## 1. Introduction — Trading Function
Historical Volatility (HV) measures the standard deviation of logarithmic price returns over a lookback period, annualized. It quantifies how much price has moved (regardless of direction) and is used as a pure volatility gauge. HV is a non-directional gate — it never contributes a bullish or bearish directional score. Traders use it to assess regime context: extreme HV warns of chaotic conditions; low HV signals a potential impending expansion.

## 2. Mathematical Formula
```
log_return[i] = ln(Close[i] / Close[i-1])
HV = σ(log_returns, period) × √(365)   // annualized (crypto-native 365-day base)
```
Where σ is the standard deviation.

> **Annualization base.** The platform uses `365` (crypto-native, continuous-trading market) rather than the traditional equity `252` (US trading days). This convention aligns the HV engine with the rest of the platform's analytics (which all annualize over 365 days, e.g. `01-00-introduction-to-quantitative-trading.md §4.1`). Changing the annualization base across engines introduces a ~20 % scale mismatch on the same price series.

## 3. Normalization
HV is a non-directional gate (`directional: false`). Its normalized value is always 0.0 (never influences directional scoring), but the state label classifies volatility level:
- HV_EXTREME_VOLATILITY → triggers a Threshold(Neutral) signal
- HV_HIGH_VOLATILITY
- HV_NORMAL_VOLATILITY
- HV_LOW_VOLATILITY

## 4. Signals
| SignalKind | Label Pattern | Trigger Condition | Direction |
|-----------|--------------|------------------|-----------|
| Threshold | EXTREME_VOLATILITY | HV at extreme levels (regime outlier warning) | Neutral |
