# Relative Volume (RVOL)

**Version:** 11.0 (2026-08-26) — see docs/CHANGELOG.md for the canonical version history.


## 1. Introduction — Trading Function

Relative Volume (RVOL) measures current volume against its rolling average to classify participation intensity. It is a **non-directional gate** — it never contributes a bullish or bearish directional score, but acts as a multiplier/filter for other indicators' signals. Traders use it to:
- Validate breakouts (institutional-level volume confirms the move)
- Identify exhaustion (climax volume at trend extremes)
- Gauge market participation (normal vs elevated vs depressed)

## 2. Mathematical Formula

```
RVOL = Volume / AverageVolume(20)
```

## 3. Normalization

> **v2.1 — non-directional gate contract.** RVOL is a non-directional gate (`directional: false`). The canonical `IndicatorEvaluation.normalized` field is **always `0.0`** (consistent with the BBWP convention; both are non-directional gates). The band values (−0.5, 0.2, 0.8, −1.0) are exposed via `IndicatorEvaluation.state_label` (`LOW_PARTICIPATION_VOLUME` / `NORMAL_PARTICIPATION_VOLUME` / `INSTITUTIONAL_BREAKOUT_VOLUME` / `EXHAUSTION_CLIMAX_VOLUME`) and `IndicatorEvaluation.values.rvol_band` (the raw signed scalar). The confluence engine reads `values.rvol_band` as a scalar gate coefficient when evaluating regime and risk, but **never as a directional voter** — applying the band value as a directional coefficient would sign-flip bearish breakouts into bullish signals.

RVOL band labels (for documentation only; the band values are stored in `values.rvol_band`):

- RVOL < 1.0: `LOW_PARTICIPATION_VOLUME`
- RVOL 1.0–1.5: `NORMAL_PARTICIPATION_VOLUME`
- RVOL 1.5–3.0: `INSTITUTIONAL_BREAKOUT_VOLUME`
- RVOL ≥ 3.0: `EXHAUSTION_CLIMAX_VOLUME` (extreme participation — mean-reversion expectation)

The signed band values encode participation regime — low/normal/institutional/exhaustion — not bullish vs bearish price direction.

## 5. Scoring

`rvol` is `directional: false`. Acts as a breakout-validation gate for S/R role-reversals, Fibonacci breakouts, and pattern confirmations. RVOL serves as an institutional-participation gauge.
