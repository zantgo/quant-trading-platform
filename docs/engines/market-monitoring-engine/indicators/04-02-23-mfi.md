# Money Flow Index (MFI) (14)

**Version:** 11.0 (2026-08-26) — see docs/CHANGELOG.md for the canonical version history.


## 1. Introduction — Trading Function
The Money Flow Index is a volume-weighted RSI that oscillates between 0-100. Like RSI, it identifies overbought (>80) and oversold (<20) conditions, but incorporates volume to weigh the strength of price moves. It is often called the "volume-weighted RSI" and is used for divergence detection and overbought/oversold signals with institutional confirmation via volume weighting.

## 2. Mathematical Formula
```
TP = (High + Low + Close) / 3
MF = TP × Volume
Positive MF = sum(MF where TP[i] > TP[i-1])
Negative MF = sum(MF where TP[i] < TP[i-1])
MR = Positive MF / Negative MF
MFI = 100 - (100 / (1 + MR))
```

## 3. Normalization
Same piecewise sigmoid as RSI, with thresholds at 20/80 instead of 30/70:
```
mfi ≥ 80: norm = -0.7 - (mfi-80)/20 × 0.3   → [-1.0, -0.7]
mfi ≤ 20: norm = 0.7 + (20-mfi)/20 × 0.3     → [0.7, 1.0]
mfi ≤ 50: norm = -(50-mfi)/30 × 0.7            → [-0.7, 0)  (BEARISH_FLOW → negative)
mfi > 50: norm = (mfi-50)/30 × 0.7             → (0, 0.7]    (BULLISH_FLOW → positive)

> **Sign convention (P0-1, v6.10.17).** The middle-band signs were
> inverted: mfi 48.9 (BEARISH_FLOW) reported +0.03 and mfi 51.8
> (BULLISH_FLOW) reported −0.04 — feeding wrong votes into L4 scoring.
> The mapping now follows the uniform RSI convention: flow below the 50
> line is bearish (negative), above is bullish (positive).
```
Labels: `MFI_OVERBOUGHT_DISTRIBUTION`, `MFI_OVERSOLD_ACCUMULATION`, `MFI_BULLISH_FLOW`, `MFI_BEARISH_FLOW`, `MFI_NEUTRAL`.

## 4. Signals
| SignalKind | Label Pattern | Trigger Condition | Direction |
|-----------|--------------|------------------|-----------|
| Threshold | MFI_OVERBOUGHT_DISTRIBUTION | MFI ≥ 80 — overbought distribution, potential reversal down | Bearish |
| Threshold | MFI_OVERSOLD_ACCUMULATION | MFI ≤ 20 — oversold accumulation, potential reversal up | Bullish |
| Threshold | MFI_BULLISH_FLOW | MFI between 50-80 with upward slope — institutional accumulation in progress | Bullish |
| Threshold | MFI_BEARISH_FLOW | MFI between 20-50 with downward slope — institutional distribution in progress | Bearish |
| Divergence | BULLISH_DIVERGENCE | Price makes lower low, MFI makes higher low — hidden volume-weighted accumulation. Detected via 20-bar SeriesDivergence. **Confirmed when (a) a candle close breaks below the nearest Support level and immediately reverses back above it (liquidity sweep / reclaim), OR (b) a candle close breaks above the nearest Resistance level (structural break); the tolerance buffer is 0.2% of level price.** | Bullish |
| Divergence | BEARISH_DIVERGENCE | Price makes higher high, MFI makes lower high — volume-weighted distribution exhaustion. **Confirmed when (a) a candle close breaks above the nearest Resistance level and immediately reverses back below it (liquidity sweep / reclaim), OR (b) a candle close breaks below the nearest Support level (structural break); tolerance 0.2%.** | Bearish |
| ZeroLineCross | MFI zero cross | MFI crosses the 50 midline (registry-declared capability; the runtime deriver's `ZERO_CROSS_KEYS` does not yet include `mfi` — emission pending). | Bullish / Bearish |

> Registry manifest (`signal_types`): Threshold, Divergence, ZeroLineCross. The ZeroLineCross row is declared capability that the deriver has not yet wired.

**Divergence Lifecycle:** Potential (oscillator disagrees with price, no structural break) → Confirmed (a candle close decisively sweeps / reclaims or breaks through the relevant S/R boundary by >0.2% tolerance). The divergence is emitted as a nested `Divergence` signal on the `mfi` key — there is no separate `mfi_divergence` registry entry or JSON key. The MFI 50 midline cross is a configuration signal (not a formal SignalKind emission) — it contributes to the `MFI_BULLISH_FLOW` / `MFI_BEARISH_FLOW` state transitions.

> **Wording precision (correction).** A previous version of this table said *"Potential → Confirmed when nearest Support level broken with 0.2% tolerance"* for the bullish signal. A *sustained downward break* of support is a **bearish structural breakdown** — it cannot confirm a **bullish reversal** divergence. The corrected confirmation rule admits two regimes: a *sweep / reclaim* (the canonical bullish trigger: price dips under support and closes back above) **or** a structural break above resistance (the canonical bullish trend change). The bear-side mirrors this.
