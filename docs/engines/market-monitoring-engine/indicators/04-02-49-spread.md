# Spread

**Version:** 11.0 (2026-08-26) — see docs/CHANGELOG.md for the canonical version history.


## Fundamental Mechanism

The **Spread** measures the distance between the best bid and best ask price as a percentage of the mid-price. It is a direct gauge of immediate market liquidity: a tight spread signals deep, efficient markets; a widening spread signals thin conditions that increase execution cost and risk.

Computed from the `OrderBookAnalysis` struct (`crates/market-analyzer/src/indicators/order_book.rs`):

```
mid = (best_bid + best_ask) / 2
spread_pct = (best_ask - best_bid) / mid × 100
```

Spread is a **non-directional gate** — it provides liquidity-quality context but does not vote on bullish/bearish direction.

## Interpretation

| Spread % | Condition | Meaning |
|----------|-----------|---------|
| < 0.05% | Tight | Liquid market — favourable execution conditions. |
| 0.05–0.15% | Normal | Standard crypto spreads. |
| > 0.15% | Wide | Thin book — elevated slippage, caution for entry. |
| > 0.2% | Widening | Liquidity drying up — avoid large orders. |

## Signals

| SignalKind | Label Pattern | Trigger Condition | Direction |
|-----------|--------------|------------------|-----------|
| Threshold | SPREAD_WIDENING | Spread exceeds the wide-spread threshold (configurable via `[order_book] spread_wide_threshold_pct`, default 0.05%) | Neutral (gate only) |

> **Scale fix (AUDIT-AIU-001).** `spread_pct` is already a percentage; the analyzer previously multiplied it by 100 again, making a real 0.015% spread render as 1.5% and firing SPREAD_WIDENING on every snapshot (and permanently inflating the execution-risk dimensions). The double-scaling is removed.

Strength scales with the spread magnitude: `strength = min(spread_pct / threshold, 1.0)`.

## Risk Integration

Spread directly feeds two risk dimensions:

- **Execution liquidity risk** (`risk.rs::assess_execution_liquidity_risk`): wide spread → +20 risk score; tight spread → −10.
- **Execution risk** (`risk.rs::assess_execution_risk`): wide spread → +25; moderate → +10.

## Normalization

```
raw_value = spread percentage
normalized = 0.0 (non-directional gate)
state_label = SPREAD_WIDENING | TIGHT
```
